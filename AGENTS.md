# МЕЖДУ — нативный клиент (Rust + wgpu)

Инструкция для любого ИИ-агента (Claude, Gemini, Jules). Читать целиком перед работой. Отвечать пользователю по-русски.

## Что это
Нативный Android-клиент игры «МЕЖДУ» — воксельного детектива о советском посёлке 1980-х. Основная игра — веб-версия в репозитории **Kejikeq/-** (JS, WebGPU, WGSL). Она остаётся главной и **только для чтения** отсюда. Этот репозиторий рисует тот же мир нативно: wgpu на Vulkan, с откатом на GLES, на Redmi 10S (Helio G95, Mali-G76 MC4) с целью 30 FPS при минимуме батареи.

## Контракт: контент-пак
Всё, что веб-версия вычисляет в JS, приходит сюда готовыми файлами. Пак собирает `node tools/export-native.mjs <out>` в репозитории Kejikeq/-:
- `manifest.json` — format, version, commit, constants (VS, WX/WY/WZ, TILE, ATLAS_W/H, флаги материалов…), files[{path, sha256, size, kind…}];
- `shaders/*.wgsl` — готовый WGSL (14 шейдеров, все проходят naga);
- `atlas/{det,pbr}_L0..4.bin.zst` — RGBA8 мип-уровни атласа, zstd, размеры в manifest. det хранит цвет/среднее ×0.25, шейдер умножает на 4;
- `tex/fog.bin`, `tex/lut.bin` — маленькие запечённые текстуры;
- `materials.bin` — f32, 256 × 8 (раскладка в manifest); `materials.json` — имена;
- `mesh/<tx>_<tz>.bin.zst` — квады макро-чанков от мешера игры; `frame/ch<N>.bin` — шаблон кадрового uniform со светом главы N (поля камеры — `perFrame` в manifest);
- `models/{faces.bin.zst,models.json,instances.bin.zst}` — модели (деревья, предметы) и их статичные экземпляры в районе мешей; расстановку снимает `node tools/check.mjs instances` из запущенной игры (только локально, в CI браузера нет — `bundle_pack.py` тогда сохраняет встроенные модели);
- `grass.bin.zst` — карта травы как буфер `gcol` renderer.js (`buildGrassMap`), вне района мешей обнулена;
- `world/<tx>_<tz>.bin.zst` — тайл 256×128×256 вокселей u16, индекс x + 256*(z + 256*y). Младший байт — материал Сна, старший — Кошмара. Воксель 0,125 м.

**Пак и шейдеры здесь не править и формат не придумывать.** Если чего-то не хватает или шейдер не принимается — напиши пользователю блок «ДЛЯ CLAUDE» с точным текстом проблемы; правка делается в Kejikeq/-.

## Устройство репозитория
- `crates/core` — формат пака (`Pack`, `Manifest`), zstd (ruzstd), sha256, проверка WGSL через naga. `cargo run --release -p mezdu-core --bin packcheck -- <пак>` — проверка пака.
- `crates/gfx` — wgpu: `Gfx::new` пробует Vulkan, затем GL; `compile_shaders`; кадр.
- `crates/app` — winit 0.30: `android_main` (NativeActivity) и десктоп `main.rs`. Переменные: `MEZDU_PACK=<папка пака>`, `MEZDU_BACKEND=gl|vulkan`. Пока на экране нет текста, цвет фона — статус: голубой = Vulkan, янтарный = откат на GL, тёмно-красный = шейдер пака не скомпилировался.
- `app/` — Gradle-оболочка без Java/Kotlin-кода: `android.app.NativeActivity` + `libmezdu.so`. **`app/src/main/jniLibs/{arm64-v8a,x86_64}/libmezdu.so` собирает CI из `crates/` и коммитит в main** — поэтому любой Gradle (в том числе AI Studio) собирает APK без Rust и NDK. Эти .so руками не трогать и не удалять; после правки Rust дождаться коммита `build: libmezdu.so …` от CI.
- `app/src/main/assets/pack` — часть пака, встроенная в APK: шейдеры, материалы, fog/lut, атлас, шаблоны света `frame/ch*.bin`, меши главы 1 (`mesh/`, тайлы x 0..2, z 8..9). При запуске копируется в каталог данных. Остальной мир придёт с обновлятором (этап 2). Обновляет её `pack.yml` (`tools/bundle_pack.py`).
- `crates/gfx/src/props.rs` — модели и экземпляры: отсечение на CPU по правилам `CULL_SHADER` (дистанция, уровни детализации `_l`/`_f`, пирамида видимости), рисуются `vsProp`+`fsProp`/`fsTree`, тени — `vsPropShadow`/`fsPropShadow`.
- `crates/gfx/src/world.rs` — проходы как в renderer.js: каскады теней (`vsShadow`/`fsShadowLeaf`, 1024², ближний 14 м, дальний 40 м, перерисовка только при сдвиге) → основной (`vsTerrain` + `fsTerrain`/`fsLeaf`, WMODE 0 = Сон, HDR + G-буфер) → финальный `fsComp` из `comp.wgsl` (небо, туман, экспозиция, AgX, LUT, виньетка, зерно). Отражения неба и BRDF печёт `env.wgsl` (`fsEnv`, `fsLut`) при загрузке. Группа 0 повторяет `L0` из renderer.js по привязкам. После основного — AO (`ao.wgsl`, ½ разрешения: 6 выборок, 6 шагов контактной тени) и SSR (`ssr.wgsl`, ¼ разрешения, 8 шагов); их читает основной проход следующего кадра (группа 0 пересобирается при смене размера). Пока заглушки: объёмный свет, DOF, история TAA. Камера: один палец — обзор, два — движение; на ПК мышь + WASD/QE.
- `.github/workflows/android.yml` — clippy → .so (cargo-ndk) → коммит .so → `gradle assembleRelease` → релиз `app` (`mezhdu.apk`).
- `.github/workflows/pack.yml` — каждые 30 мин берёт main из Kejikeq/- (секрет `GAME_REPO_TOKEN`), собирает и проверяет пак → релиз `pack` и лёгкий пак в assets. Имена файлов в релизе: `/` → `__` (`mezdu_core::asset_name`).
- AI Studio: не переписывать проект в Kotlin/Compose и не заменять `app/`; только собирать и запускать. Если сборка падает — исправлять Gradle-файлы, не трогая `crates/` и `jniLibs`.

## Правила
- Rust, без Java/Kotlin (исключение — минимальная прослойка для установки APK, если без неё никак).
- Никаких аллокаций в кадре; тяжёлый CPU — в потоках; рендер останавливается в фоне (`suspended`).
- Перед коммитом: `cargo clippy --release -- -D warnings` и то же для `--target aarch64-linux-android -p mezdu-app`. Десктоп: `MEZDU_PACK=pack cargo run --release -p mezdu-app` — смотреть лог.
- Крейты добавлять только с причиной. Версии: wgpu 30, naga 30, winit 0.30, glam 0.34; Rust 1.97.0 (закреплён в CI).
- Один этап за запрос. Итог пользователю — до 8 строк: что сделано, что проверить на телефоне, блок «ДЛЯ CLAUDE», если нужен.
- Логику, сюжет и UI из JS не переписывать, пока пользователь не попросит.
