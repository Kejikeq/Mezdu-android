# МЕЖДУ — нативный клиент (Rust + wgpu)

Инструкция для любого ИИ-агента (Claude, Gemini, Jules). Читать целиком перед работой. Отвечать пользователю по-русски.

## Что это
Нативный Android-клиент игры «МЕЖДУ» — воксельного детектива о советском посёлке 1980-х. Основная игра — веб-версия в репозитории **Kejikeq/-** (JS, WebGPU, WGSL). Она остаётся главной и **только для чтения** отсюда. Этот репозиторий рисует тот же мир нативно: wgpu на Vulkan, с откатом на GLES, на Redmi 10S (Helio G95, Mali-G76 MC4) с целью 30 FPS при минимуме батареи.

## Контракт: контент-пак
Всё, что веб-версия вычисляет в JS, приходит сюда готовыми файлами. Пак собирает `node tools/export-native.mjs <out>` в репозитории Kejikeq/-:
- `manifest.json` — format, version, commit, constants (VS, WX/WY/WZ, TILE, ATLAS_W/H, флаги материалов…), files[{path, sha256, size, kind…}];
- `shaders/*.wgsl` — готовый WGSL (14 шейдеров, все проходят naga);
- `atlas/{det,pbr}_L0..4.bin.zst` — RGBA8 мип-уровни атласа, zstd, размеры в manifest. det хранит цвет/среднее ×0.25, шейдер умножает на 4;
- `tex/fog.bin`, `tex/lut.bin` — маленькие запечённые текстуры;
- `materials.bin` — f32, 256 × 8 (раскладка в manifest); `materials.json` — имена;
- `mesh/<tx>_<tz>.bin.zst` — квады макро-чанков от мешера игры; `frame/ch<N>.bin` — шаблон кадрового uniform со светом главы N (поля камеры — `perFrame` в manifest);
- `models/{faces.bin.zst,models.json,instances.bin.zst}` — модели (деревья, предметы) и их статичные экземпляры в районе мешей; расстановку снимает `node tools/check.mjs instances` из запущенной игры (только локально, в CI браузера нет — `bundle_pack.py` тогда сохраняет встроенные модели);
- `grass.bin.zst` — карта травы как буфер `gcol` renderer.js (`buildGrassMap`), вне района мешей обнулена;
- `world/<tx>_<tz>.bin.zst` (в APK — тайлы главы 1, для столкновений) — тайл 256×128×256 вокселей u16, индекс x + 256*(z + 256*y). Младший байт — материал Сна, старший — Кошмара. Воксель 0,125 м.

**Пак и шейдеры здесь не править и формат не придумывать.** Если чего-то не хватает или шейдер не принимается — напиши пользователю блок «ДЛЯ CLAUDE» с точным текстом проблемы; правка делается в Kejikeq/-.

## Устройство репозитория
- `crates/core` — формат пака (`Pack`, `Manifest`), zstd (ruzstd), sha256, проверка WGSL через naga. `cargo run --release -p mezdu-core --bin packcheck -- <пак>` — проверка пака.
- `crates/gfx` — wgpu: `Gfx::new` пробует Vulkan, затем GL; `compile_shaders`; кадр.
- `crates/app` — winit 0.30: `android_main` (NativeActivity) и десктоп `main.rs`. Переменные: `MEZDU_PACK=<папка пака>`, `MEZDU_BACKEND=gl|vulkan`, `MEZDU_TIME=<с>` (остановить анимацию для сравнения скриншотов). Пока на экране нет текста, цвет фона — статус: голубой = Vulkan, янтарный = откат на GL, тёмно-красный = шейдер пака не скомпилировался.
- `app/` — Gradle-оболочка без Java/Kotlin-кода: `android.app.NativeActivity` + `libmezdu.so`. **`app/src/main/jniLibs/{arm64-v8a,x86_64}/libmezdu.so` собирает CI из `crates/` и коммитит в main** — поэтому любой Gradle (в том числе AI Studio) собирает APK без Rust и NDK. Эти .so руками не трогать и не удалять; после правки Rust дождаться коммита `build: libmezdu.so …` от CI.
- `app/src/main/assets/pack` — часть пака, встроенная в APK: шейдеры, материалы, fog/lut, атлас, шаблоны света `frame/ch*.bin`, меши главы 1 (`mesh/`, тайлы x 0..2, z 8..9). При запуске копируется в каталог данных. Остальной мир придёт с обновлятором (этап 2). Обновляет её `pack.yml` (`tools/bundle_pack.py`).
- `crates/game` — логика игры без GPU, перенос из `src/game` Kejikeq/-: `voxels.rs` (воксели мира из пака, `solid` как duality.js), `player.rs` (ходьба, столкновения AABB, подъём на ступени, гравитация; камера за плечом: тонкий луч обзора, плечо съезжает к центру у стен, стены сбоку сдвигают камеру вбок, задержка перед отъездом, в тесноте камера заходит за спину — player.js updateCamera), `rig.rs` (фигура героя из 8 частей, позы idle/walk — writeRig).
- Управление (`crates/app`): палец в левых 45 % экрана — джойстик, остальные пальцы — обзор; на ПК WASD, Shift — бег, мышь с зажатой кнопкой — обзор. Старт главы 1 — точка `spawn` из chapters_data.js. Без вокселей в паке — свободная камера.
- `crates/gfx/src/props.rs` — модели и экземпляры: отсечение на CPU по правилам `CULL_SHADER` (дистанция, уровни детализации `_l`/`_f`, пирамида видимости), рисуются `vsProp`+`fsProp`/`fsTree`, тени — `vsPropShadow`/`fsPropShadow`.
- `crates/gfx/src/world.rs` — проходы как в renderer.js: каскады теней (`vsShadow`/`fsShadowLeaf`, 1024², ближний 14 м, дальний 40 м, перерисовка только при сдвиге) → основной (`vsTerrain` + `fsTerrain`/`fsLeaf`, WMODE 0 = Сон, HDR + G-буфер) → финальный `fsComp` из `comp.wgsl` (небо, туман, экспозиция, AgX, LUT, виньетка, зерно). Отражения неба и BRDF печёт `env.wgsl` (`fsEnv`, `fsLut`) при загрузке. Группа 0 повторяет `L0` из renderer.js по привязкам. После основного — AO (`ao.wgsl`, ½ разрешения: 6 выборок, 6 шагов контактной тени) и SSR (`ssr.wgsl`, ¼ разрешения, 8 шагов); их читает основной проход следующего кадра (группа 0 пересобирается при смене размера). TAA встроен в `fsComp`: дрожание проекции по Halton (8 кадров), две текстуры истории попеременно, сброс при скачке камеры > 3 м. Объёмный туман и лучи — `vol.wgsl` (½ разрешения, 10 шагов, через кадр; `counts.z` = 10, при 0 шейдеры дают простой туман по дальности). Пока заглушка: DOF. Камера: один палец — обзор, два — движение; на ПК мышь + WASD/QE.
- `.github/workflows/android.yml` — clippy → .so (cargo-ndk) → коммит .so → `gradle assembleRelease` → релиз `app` (`mezhdu.apk`).
- `.github/workflows/pack.yml` — каждые 5 мин берёт main из Kejikeq/- (секрет `GAME_REPO_TOKEN`), собирает и проверяет пак → релиз `pack` и лёгкий пак в assets. Имена файлов в релизе: `/` → `__` (`mezdu_core::asset_name`).
- AI Studio: не переписывать проект в Kotlin/Compose и не заменять `app/`; только собирать и запускать. Если сборка падает — исправлять Gradle-файлы, не трогая `crates/` и `jniLibs`.

## Правила
- Rust, без Java/Kotlin (исключение — минимальная прослойка для установки APK, если без неё никак).
- Никаких аллокаций в кадре; тяжёлый CPU — в потоках; рендер останавливается в фоне (`suspended`).
- Перед коммитом: `cargo clippy --release -- -D warnings`; для Android — `cargo ndk -t arm64-v8a -P 26 clippy --release -p mezdu-app -- -D warnings` (нужен NDK: `ring` из TLS обновлятора компилирует C; без NDK это проверяет CI). Десктоп: `MEZDU_PACK=pack cargo run --release -p mezdu-app` — смотреть лог.
- Крейты добавлять только с причиной. Версии: wgpu 30, naga 30, winit 0.30, glam 0.34; Rust 1.97.0 (закреплён в CI).
- Один этап за запрос. Итог пользователю — до 8 строк: что сделано, что проверить на телефоне, блок «ДЛЯ CLAUDE», если нужен.
- Логику, сюжет и UI из JS не переписывать, пока пользователь не попросит.

## Этапы
- [x] **1. Каркас.** Окно, wgpu с Vulkan→GL, очистка экрана цветом статуса, FPS в логе, компиляция всех шейдеров встроенного пака, Gradle-оболочка, CI с .so и APK.
- [x] **2. Обновления.** `crates/updater` (ureq + rustls, корни Mozilla; `SSL_CERT_FILE` подменяет их на ПК за TLS-прокси): при запуске в фоне читает `manifest.json` релиза `pack`, докачивает файлы с другим sha256 (`asset_name`), собирает `pack.tmp` → `pack.next` и подменяет `pack`, когда мир строится заново: при запуске или возврате из фона (`install_staged` в `resumed`); пока игра открыта, проверяет релиз каждые 5 мин (`watch`). Пак беднее установленного (нет вида файлов, кроме `models`) пропускается; `models` всегда берутся из установленного. Встроенный в APK пак копируется в каталог данных один раз на коммит (`bundled.txt`), скачанный не затирает. Новый APK: `apk-version.txt` против `MEZDU_BUILD` (коммит сборки из CI) — пока только в лог, предложение установить появится вместе с интерфейсом (7.2). Мир из релиза — все тайлы: земля отсекается по 180 м и пирамиде видимости.
- [x] **3. Атлас и материалы на GPU.** Текстуры det/pbr с 5 мипами, таблица материалов, fog/lut.
- [x] **4. Мир.** Меши макро-чанков из пака (мешер игры в export-native), отрисовка `vsTerrain`/`fsTerrain`/`fsLeaf`, камера-облёт; квады и вызовы в логе. Дальше: свой мешер на Rust для правок мира, отсечение по пирамиде видимости, вода, модели (деревья, предметы), текст на экране.
- [ ] **5. Проходы рендера** в порядке веб-версии (`src/gfx/renderer.js` в Kejikeq/-). Готово: тени (2 каскада, с деревьями и предметами), запекание окружения, композит `fsComp`, модели и деревья главы 1, трава (`vsGrass`/`fsGrass`, 48×48 клеток × 16 травинок, радиус 16 м). AO и SSR, TAA, объёмный туман. Осталось: вода (`vsWater`), автоэкспозиция (`exposure.wgsl`), DOF; замер времени проходов.
- [x] **6. Профиль качества** (`world::Quality`): Vulkan = `QUALITY` игры (сцена и `fsComp` не больше 1,1 Мп, потом растяжение на экран; AO, SSR, объём); GL = 0,6 Мп без экранных проходов. Кадры — 30 FPS (`about_to_wait` + `WaitUntil`, между кадрами цикл спит). На GL мир пока не строится: в `world.wgsl` есть `textureLoad` из текстур глубины (тени, глубина), у GLSL такого нет — `Gfx::try_world` ловит ошибку, экран остаётся янтарным. Для GL нужна правка шейдеров в Kejikeq/- (ДЛЯ CLAUDE).

- [ ] **7. Игра** (по шагу за запрос): 7.1 игрок и управление — готово (без коллайдеров мебели и дверей: в JS это `hitsPropCollider`); 7.2 меню и загрузка (egui); 7.3 сохранения (слоты, автосохранение, удаление); 7.4 взаимодействие, предметы, рюкзак; 7.5 сюжет и диалоги (тексты из пака); 7.6 звук.
